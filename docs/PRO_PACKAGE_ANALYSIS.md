## 3. 发布架构观察

包内同时存在混淆后的 JavaScript、`sidecar/payload.enc` 和 Windows x64、macOS x64/arm64 平台程序。可以确认这是包含受保护载荷和平台程序的发布包，不能据此推断载荷内容、授权机制或全部业务的运行位置。

目录名中的 `all` 不足以证明所有系统支持；当前可见 sidecar 平台目录不包含 Linux。本项目不照搬此发布架构：Funplay 已提供可扩展底座，是否新增外部进程应由自有需求决定。
