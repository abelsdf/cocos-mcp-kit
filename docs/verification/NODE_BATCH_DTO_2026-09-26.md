# FR-29 节点批次 DTO 与只读预检验证（2026-09-26）

## 范围

`validate_node_batch` 是 `core` 与 `full` 均可见的只读工具，只对 Cocos MCP Kit 自定义的 [v1 DTO](../NODE_BATCH_DTO.md) 做本地静态预检。它不查询或写入 Creator 场景。返回的父先子顺序、局部 ID 和待处理引用计划不表示组件类型、资源、目标父节点或写入持久化已通过 Creator 验证；此阶段尚无场景批次创建工具。

## 检查

| 检查 | 结果 |
| --- | --- |
| 纯逻辑与注册 | 验证多类引用、内部身份重映射、重复根、循环/断链、外部引用策略、原型污染键、字段冲突、规模限制、部分清理报告及循环输入拒绝；工具测试确认只读注解且不调用场景桥接。全量 1055 项测试通过、0 失败、0 跳过；66 个脚本语法检查、工具文档生成校验和发布检查通过。 |
| Creator 3.8.8 正式入口 | 保存关闭工程后，备份并同步 10 个扩展文件；重开后与源码 SHA-256 全部一致。`/health` 显示目标工程、版本 0.1.0，`tools/list` 返回 138 项，`validate_node_batch` 的 `readOnlyHint=true`。正式调用有效两节点批次返回 `panel`→`label` 的父先子顺序及 `remap_on_create`；重复根返回 `DUPLICATE_ROOT`，默认策略下外部引用返回 `EXTERNAL_REFERENCE_REJECTED`，均为 `valid=false` 且无创建计划。 |

失败清理与单次 Undo 目前只定义报告和边界，没有执行 Creator 删除或撤销；阶段 1.5 中的名称冲突、真实身份映射、故障注入与写入适配仍为待办。版本保持 0.1.0 Unreleased。
