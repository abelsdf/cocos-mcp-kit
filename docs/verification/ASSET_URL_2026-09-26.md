# OP-082 资源 URL 查询验证（2026-09-26）

## 范围与边界

新增 full-profile 只读 `query_asset_url`，接受精确资源 UUID、db URL、工程 `assets/` 相对路径或项目资源目录内的绝对路径。工具复用 OP-081 的 UUID 身份和子资源父子关系检查，再以原生 `query-url` 查询 UUID，要求其返回值通过 `query-uuid` 和 `query-asset-info` 回指同一个 UUID、规范 URL 与类型。顶层 `url` 仅在全部检查通过时返回 asset-db 记录中的规范 URL；缺失、未导入、原生映射缺失或冲突时为 `null`。不读取或修改资源源文件。

此前 OP-080/081 的 Creator 3.8.8 现场检查显示：Texture2D 子资源的 `query-asset-info.url` 是 `db://assets/McpKitValidation/ArrowHint.png/texture`，而原生 `query-url` 返回 `db://assets/McpKitValidation/ArrowHint.png@6c48a`。本工具将后者放入 `nativeMapping.url` 并标记 `isCanonical: false`，不把别名当作规范 URL；OP-082 正式入口已再次确认这一差异。
