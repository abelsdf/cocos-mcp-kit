### Creator 3.8.8 首轮实测（2026-09-18）

- 独立工程 `CocosMcpTest2D` 已加载本扩展；`/health` 与 MCP `initialize` 返回相同工程身份，当前 core 配置暴露 39/105 个工具。`get_editor_state`、场景层级、资源列表等查询在真实编辑器中返回。
