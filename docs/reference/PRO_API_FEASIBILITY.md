# Pro 接口与 Cocos 官方 API 可行性逐项对照

版本：0.5　分析日期：2026-09-12　范围修订：2026-09-18　目标核验版本：Creator 3.8.8 / Windows

本表以已激活 Pro 正常 `tools/list` 的232个枚举条目为范围，分析独立实现路线，不复用其实现、模板或知识正文。接口目录统计为224个action加8个topic；宣传231项的差异仍未解释。Funplay候选工具来自本地105项full目录，**候选入口不代表功能完整对等或已经通过真实编辑器验收**。

## 判定口径

| 类别 | 项数 | 含义 |
| --- | ---: | --- |
| A：公开 API 明确 | 36 | 官方文档或本机官方引擎提供对应基础API；仍需扩展适配和保存/运行验收。 |
| B：组合实现可行 | 115 | 可以独立编排公开能力实现；仍有组合、类型转换、引用和平台边界，部分依赖C类保存适配。 |
| C：原生适配待核验 | 66 | 手册只描述交互或Funplay有候选消息；尚缺确切原生契约/持久化证据，不能承诺行为一致。 |
| D：可提供替代实现 | 15 | 自有面板/剪贴板等功能可实现；替代交互不代表与原生视图或格式兼容。 |

A+B共151项有基础API或组合路线，C类66项需继续验证，D类15项采用明确替代路线。**原始逐项 JSON 的232项运行验证状态均为“未测试”基线**；后续部分实测进展记录在本表对应行及 `docs/verification`。这些类别不是工期估算、实现进度、成功率或完整Pro替代承诺。

官方依据与本地证据见[分析报告的来源表](../COCOS_DOCS_ANALYSIS.md#来源与证据)。机器可读记录见[逐项JSON](./pro-api-feasibility.json)，其中验证状态仍保留最初的未测试基线；本表部分行及 `docs/verification` 已补充后续 Creator 实测证据，不应把基线状态当作当前全部功能的运行结论。

每组共有边界适用于全部行；JSON中另保存单项限制。需求编号关联所属模块，优先级标注首版或增强范围；原生视图、剪贴板和预制体编辑模式作为P1增强，不因关联P0基础模块而全部进入首版。状态“未测试”同时不表示新增功能已经开发。
