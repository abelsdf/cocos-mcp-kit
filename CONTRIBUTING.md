# Contributing to Cocos MCP Kit

Cocos MCP Kit is an independent open-source fork of Funplay MCP for Cocos. Contributions to reliability, editor compatibility, documentation, and development workflows are welcome.

For local development, place this repository at `extensions/cocos-mcp-kit` inside a Cocos Creator project, restart Creator, and open **Cocos MCP Kit > MCP Server**. Run `npm run check` and `npm test` before submitting changes. Scene and asset mutations also need a real editor save-and-reopen check.

Keep the upstream copyright and complete MIT terms in [LICENSE](./LICENSE). Implement new capabilities independently from public Cocos documentation and license-compatible sources. Do not copy code, build outputs, templates, assets, or documentation from commercial packages or projects that restrict reuse. Check the license of every third-party dependency or asset before adding it.
